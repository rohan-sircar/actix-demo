# Add `matched_at` to likes table

## Goal

Sort matches by when the mutual like actually formed (when the other user reciprocated), not by when the current user first liked the other's pet.

**Current behavior:** `list_matches()` orders by `likes.created_at` — the timestamp when *I* liked someone's pet. If I liked on Monday and they liked back on Friday, the match sorts under Monday.

**Desired behavior:** Matches sort by `matched_at` — the timestamp when the reciprocal like was created (Friday in the example above).

## Steps

### 1. Create migration: `2026-06-28-000000_add_matched_at_to_likes`

**`up.sql`:**
```sql
ALTER TABLE likes ADD COLUMN matched_at TIMESTAMPTZ;
```

**`down.sql`:**
```sql
ALTER TABLE likes DROP COLUMN IF EXISTS matched_at;
```

Column is nullable — existing records won't have it, and only matched rows will be populated.

### 2. Run migration

```bash
diesel migration run
```

This regenerates `src/schema.rs` automatically.

### 3. Update `Like` model (`src/models/likes.rs`)

Add `matched_at: Option<chrono::NaiveDateTime>` to the `Like` struct (line ~117). The field is `Option` because the column is nullable.

```rust
pub struct Like {
    pub id: LikeId,
    pub user_id: UserId,
    pub pet_owner_id: UserId,
    pub pet_id: PetId,
    pub direction: LikeDirection,
    pub is_match: bool,
    pub matched_at: Option<chrono::NaiveDateTime>,  // NEW
    pub created_at: chrono::NaiveDateTime,
}
```

Also update the test at line ~259 that constructs a `Like` instance.

### 4. Update `create_like()` (`src/actions/likes.rs`)

When setting `is_match = true` (lines 77-81), also set `matched_at`:

```rust
if is_match {
    diesel::update(likes::likes.filter(likes::id.eq(inserted_id)))
        .set((
            likes::is_match.eq(true),
            likes::matched_at.eq(diesel::dsl::now()),
        ))
        .execute(conn)?;

```

### 5. Update `list_matches()` (`src/actions/likes.rs`)

- Change sort order from `likes::created_at.desc()` to `likes::matched_at.desc()` (line 193)

### 6. Update `LikeWithPet` model (`src/models/likes.rs`)

Add `matched_at: Option<chrono::NaiveDateTime>` to the response struct (line ~177). This propagates to the API response and OpenAPI docs.

Update all three list functions (`list_likes_sent`, `list_likes_received`, `list_matches`) to pass `like.matched_at` when constructing `LikeWithPet`.
